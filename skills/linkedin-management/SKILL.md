# LinkedIn Management

## Overview
Use this skill to run end-to-end LinkedIn management: positioning, profile optimization, content production, engagement routines, outreach messaging, and performance reviews.

## Workflow

1. Define objective and audience.
2. Audit current profile and recent activity.
3. Build a weekly content and engagement plan.
4. Draft assets (posts, comments, DM sequences) with clear CTAs.
5. Review performance and iterate.

## 1) Define objective and audience

Capture these inputs before producing content:

- Primary objective: thought leadership, lead generation, hiring, partnerships, or career growth.
- Target audience: role, seniority, industry, and region.
- Offer and proof points: outcomes, case studies, numbers.
- Voice constraints: tone, banned phrases, reading level.

If any input is missing, ask concise clarifying questions before drafting.

## 2) Audit profile and activity

Evaluate the profile in this order:

- Headline clarity (role + niche + value).
- About section (credibility + outcomes + CTA).
- Featured section relevance.
- Experience bullets (impact-first, quantified).
- Creator mode signals: topics and consistency.

Provide fixes as specific rewrites, not only critique.

## 3) Build a weekly plan

Create a 7-day plan with:

- 2-4 core posts (educational/story/opinion/proof mix).
- 10-20 intentional comments on ICP-adjacent creators.
- 5-15 personalized connection requests.
- 3-8 follow-up DMs tied to recent interactions.

Use this post mix baseline:

- 40% educational how-to
- 30% personal story/lesson
- 20% social proof/case insight
- 10% contrarian or industry POV

## 4) Draft content and outreach assets

For each post draft, include:

- Hook options (3 variants).
- Full post body with short paragraphs.
- CTA options (comment, DM keyword, link-in-comment, soft ask).
- Optional repurposing notes (carousel/newsletter/video script).

When drafting comments and DMs:

- Personalize with context from profile/post.
- Keep comments useful and specific.
- Keep DMs brief, low-pressure, and permission-based.
- Never fabricate achievements, clients, or metrics.

## 5) Review performance and iterate

Use a weekly review format:

- Inputs: posts published, comments left, DMs sent.
- Output metrics: impressions, engagement rate, profile views, connection acceptance, reply rate.
- Learning: top hooks, strongest topics, weakest CTA.
- Next-week changes: double down, improve, stop.

When data is partial, state assumptions explicitly and provide a low-confidence note.
